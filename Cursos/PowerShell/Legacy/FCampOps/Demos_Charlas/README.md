# Demos y charlas de FCampOps

Selección revisada de scripts demostrativos procedentes del repositorio privado `Bravecold/FCampOps`.

## Alcance

Esta primera migración conserva únicamente ejemplos autocontenidos y reutilizables:

- simulación de moneda y dados;
- síntesis de voz;
- presentaciones en consola con PowerShellPoint.

Los archivos mantienen los avisos de autoría incluidos en sus fuentes. Antes de publicar se comprobó que no contienen claves privadas, certificados, cadenas de conexión ni credenciales incrustadas.

## Exclusiones

No se migraron materiales de clientes, archivos de `Landmark`, certificados, claves, binarios, instaladores ni guías completas de cursos. Los ejemplos de laboratorio con contraseñas de muestra o configuraciones de infraestructura también quedaron fuera.
